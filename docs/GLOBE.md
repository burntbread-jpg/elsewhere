# 첫 화면 3D 지구본

사용자 요청으로 첫 화면의 대표 이미지를 인터랙티브 지구본으로 변경했습니다. 기존 홈과 여행기는 Git 이력에 보존됩니다.

- 드래그/한 손가락: 회전. 표면 클릭: 해당 지점으로 카메라 이동 및 확대.
- +/− 버튼 및 두 손가락 제스처: 확대/축소. 전체 보기: 초기 아시아 구도 복귀.
- 사진 썸네일: 첫 클릭은 위치 확대, 같은 사진을 다시 누르면 여행기 열기.
- 하단 장소 버튼은 키보드로도 해당 위치를 선택할 수 있습니다.
- 사진은 위도·경도로 구면 위에 투영됩니다. 뒷면 사진은 숨기고, 가까운 썸네일은 옆으로 분산하며 위치 점은 원래 좌표를 유지합니다.
- 예시 사진 2장은 제주(33.5,126.5), 서울(37.57,126.98)에 배치했습니다. 실제 촬영지나 사용자 방문 사실이 아닙니다.
- 실제 사진 추가 시 `src/components/Globe.astro`의 `pins` 목록에 승인된 공개 좌표, 이미지, 여행기 링크를 넣습니다. 집·정확한 숙소 등 민감 좌표는 넣지 않습니다. 현재는 자동 EXIF 추출을 하지 않습니다.
- Three.js WebGL, CSS/DOM 사진 마커. 자동 회전 없음, reduced-motion 시 즉시 이동, 화면 밖에서는 렌더링 일시 중지. WebGL 실패 시 여행기 목록을 계속 사용할 수 있습니다.

지도 데이터: Natural Earth 1:110m land (public domain), `public/maps/land.geojson`. 출처 https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson . 이 지도는 여행 탐색용 개략도이며 상세 행정경계/측량용이 아닙니다.

지구본 스크립트는 홈에서만 로딩됩니다. 초기 Three.js 번들은 gzip 약 139KB로 기존 정적 홈보다 무거우며, 실제 기기의 성능 지표는 추가 측정이 필요합니다.
